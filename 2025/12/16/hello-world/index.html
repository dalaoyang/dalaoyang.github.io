最近开始研究 AI 了

作为一名 Java 后端，最近感觉不学点 AI 真的要落伍了。

这两天试着用了一下 DeepSeek 和 ChatGPT 写代码，说实话，挺震撼的。

以前写个复杂的 SQL 或者正则，可能要查半天百度，现在直接扔给 AI，几秒钟就出来了。虽然有时候代码不能直接跑，但思路基本上是对的。

下阶段计划

打算先不碰太底层的算法（毕竟数学早还给老师了），先从应用层入手：

  1. 研究一下 Spring AI，看怎么把大模型接入到现在的 Java 项目里。
  2. 试着部署一个本地模型玩玩。

不得不感慨，技术迭代太快了，还得继续卷啊！😂
